This project designed and implemented a scalable  Axon Systolic Array over multiple phases to accelerate Deep Learning workloads efficiently. Phase one focused on evaluating Weight-Stationary and Output-Stationary dataflows within a single Processing Element using Principal Diagonal Feeding to minimize latency. When scaling the grid up to , a critical physical I/O barrier arose where pin requirements exceeded the Spartan-7 FPGA's 400-pin limit. We overcame this by designing a Step-wise I/O Management system that successfully reduced the pin usage. The final phase was about using Zero-Gating for power efficiency and a Pipelined MAC unit to resolve WNS. Hardware benchmarking in Xilinx Vivado analysed power, area, and timing trade-offs, evaluating ADP and PDP products across eight different Approximate Multipliers. In conclusion, the architecture demonstrated highly efficient scaling, achieving predictable operational latencies of 12, 24, 48, and 96 cycles for 4x4, 8x8, 16x16 and 32x32 grids, respectively.
